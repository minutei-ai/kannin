# Kannin

Kannin is a standalone OSS repository. Keep deployment-specific configuration and credentials outside its tracked tree.

Author Worker and tooling sources in TypeScript with Effect. Rust owns the WASM engine. JavaScript artifacts are generated by the native build, never authored.

R2 owns all canonical search state. Never introduce SQLite, FTS5, D1, KV or Durable Object storage for documents, postings, manifests, receipts or outboxes. Durable Objects coordinate operations using disposable memory. Vectorize owns vector search.

Effect Schema owns runtime contracts in `src/protocol.ts`. Decode external values at their boundary. Preserve declared failures and native failure causes. Rust owns tokenization, compressed immutable segments, positional postings, BM25 scoring and exact pruning. Filters, tombstones and live global statistics must apply before text top-k.

Alchemy owns infrastructure in `alchemy.run.ts`; commands use the native `minutei` profile. Keep secrets outside the repository. Inspect the resolved installed APIs before adding adapters or package patches. Never publish provisioning imports into the Worker bundle.

Cache immutable segment bytes and derived immutable structures. The explicit edge-eventual text contract may cache a point-in-time manifest for less than one second, measured from before the R2 read; minimumSequence bypasses an insufficient snapshot. Strong reads never use snapshot caches. Authenticate every public namespace request. Authorization never enters shared HTTP caches. Snapshot caches remain internal and bucket/namespace scoped. Cache misses, eviction or unavailability must preserve canonical R2 behavior. Keep cache identities scoped to their bucket and object version.

Use `bun run check` as the gate. It includes formatting, full all/pedantic/nursery Clippy on native and WASM targets, Rust/WASM build, strict type-aware Oxlint with the official Effect preset, the Effect-patched native TypeScript compiler, and workerd/Rust tests. Lint rejection probes must remain executable. Fix findings without suppressions. Keep generated outputs generator-owned and scratch artifacts outside this repository.

On shared hosts, run at most one heavy command at a time and enforce memory, swap and CPU limits at the native process boundary. Confirm the previous process is terminal before starting another build, lint suite or benchmark. Inspect only owned processes and never terminate another agent's work. Cargo concurrency belongs to `.cargo/config.toml`.

When a build exceeds the shared host's resource budget, use the existing GitHub check workflow on a candidate branch. Download its generated Worker artifact only after the gate passes. Keep candidate validation separate from publication to main and Cloudflare deployment.

Report local checks, Cloudflare deployment, real Vectorize behavior, ranking quality and comparable Turbopuffer benchmarks separately. Never infer performance parity from synthetic local results. Maintain public limits and remaining delivery gates in the README and architecture document.
