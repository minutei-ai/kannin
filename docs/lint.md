# Static checks

`bun run check` runs formatting, release WASM generation, type-aware Oxlint, native and WASM Clippy, independent TypeScript checking, and the local test suites. The package preparation hook installs the official Effect compiler diagnostics into Oxlint and its Go type checker. Frozen installation preserves the resolved toolchain and declared Alchemy patch.

TypeScript uses the official strict Effect preset with correctness, suspicious and performance diagnostics promoted to errors. Unsafe values, assertions, unhandled promises/effects and mismatched schemas are rejected. A small typed Oxlint plugin enforces immutable declarations, explicit branches and failure paths, explicit exports and the absence of authored comments. Native immutable using declarations remain valid for deterministic resource disposal. Native restricted-import checks keep provisioning, host APIs and SQL clients out of executable Worker imports while allowing erased native types. Generated bundles and bindings are excluded from authored-source lint.

Two group defaults are deliberately curated: `no-await-in-loop` conflicts with serial namespace writes, bounded sequential I/O, build dependencies and comparable latency sampling; `no-array-sort` conflicts with mutation of the scorer's owned bounded candidate buffer. Neither rule proves concurrency or ownership correctness. Tests cover write serialization, deterministic ordering and exact pruning instead. Unused lint suppressions are rejected; no file-wide suppressions are used.

Rust forbids unsafe code and denies ignored results, unused lifetimes/qualifications, unreachable exports and unmet lint expectations. Clippy's complete stable group is fatal, with extra restrictions for unwrap, expect, panic, placeholders, lint suppression, error erasure, discarded results, leaks, process exit and large stack allocations. Release builds keep overflow checks enabled. Clippy runs for all native targets/features and separately for the release WASM library, because conditional WASM exports can have findings absent from native builds. Parser and WASM serialization failures return explicit errors.

Executable probes verify valid Effect code passes and deliberate type, promise, Effect, syntax and Rust safety violations fail by exit code and diagnostic. These probes distinguish a functioning policy from an inert configuration. This is a concrete enforced gate; there is no objective metric that establishes a lint configuration as the strongest in the world. Remaining Rust opportunities include a full pedantic policy and conversion of indexing and casts to checked operations throughout scoring.

The native Oxlint plugin rejects authored `.js`, `.jsx`, `.mjs` and `.cjs` files. A rejection probe exercises actual file selection, while generated deployment artifacts stay generator-owned. Worker and tooling sources are TypeScript with Effect; the engine is Rust/WASM.
